# Endless Racer (UE 4.21)

Pointer to the downloaded MIT project from
[Tomiinek/UE4_Endless_Racer](https://github.com/Tomiinek/UE4_Endless_Racer).

The checkout lives outside git (gitignored download target):

```text
third_party/racing/UE4_Endless_Racer/Endless.uproject
```

```bash
make download-endless   # clone source
make endless-racer      # open in Unreal Editor when UE4/UE5 is installed
```

Engine association in the `.uproject` is **4.21**. On a newer editor, accept
the convert prompt or open via File → Open Project.
